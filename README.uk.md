# PowerToys Run StackOverflow Plugin 🇺🇦

Плагін для швидкого пошуку на StackOverflow прямо з Windows launcher.

## ✨ Можливості

- 🔍 **Швидкий пошук**: `so <запит>` для миттєвого пошуку
- ⚡ **Швидкість**: <1 секунда для кешованих запитів
- 📊 **Детальна інформація**: рейтинг, відповіді, теги
- 💾 **Розумний кеш**: 50 запитів, 1 година TTL
- 🔐 **Опціональний API ключ**: 300 → 10,000 запитів/день
- 🎨 **Підтримка тем**: автоматичне перемикання світла/темряви

## 📥 Встановлення

1. Завантажте ZIP для вашої архітектури:
   - `StackOverflow-1.0.0-x64.zip` для x64
   - `StackOverflow-1.0.0-arm64.zip` для ARM64

2. Розпакуйте в папку плагінів PowerToys:
   ```
   %LOCALAPPDATA%\Microsoft\PowerToys\PowerToys Run\Plugins\StackOverflow\
   ```

3. Перезапустіть PowerToys

## 🚀 Використання

1. Відкрийте PowerToys Run (`Alt+Space`)
2. Введіть: `so python lists`
3. Виберіть результат (стрілки) і натисніть Enter
4. Правий клік → копіювати посилання

### Приклади запитів

```
so async await c#
so python list comprehension
so javascript promises
so react hooks
```

## 🔑 Налаштування API Ключа (Опціонально)

### Навіщо потрібен?
- Без ключа: 300 запитів/день
- З ключем: **10,000 запитів/день**

### Як налаштувати?

1. **Отримайте ключ**:
   - Перейдіть: https://stackapps.com/apps/oauth/register
   - Заповніть форму
   - Скопіюйте "Key"

2. **Налаштуйте плагін**:
   - `so test` в PowerToys Run
   - Правий клік → "⚙️ Configure API Key..."
   - Створіть `settings.json`:

```json
{
  "apiKey": "ВАШ_КЛЮЧ",
  "useApiKey": true
}
```

3. **Перезапустіть PowerToys**

Детальна інструкція: [API_KEY_SETUP.md](API_KEY_SETUP.md)

## 📊 Формат результатів

```
Назва питання
↑1234 • 5 answers ✓ • python list comprehension
```

- `↑1234` - рейтинг (голоси)
- `5 answers` - кількість відповідей
- `✓` - є прийнята відповідь
- `python list comprehension` - теги
