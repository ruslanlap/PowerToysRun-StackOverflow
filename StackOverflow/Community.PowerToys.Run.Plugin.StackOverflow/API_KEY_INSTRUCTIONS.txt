QUICK SETUP (5 minutes):

1. GET YOUR API KEY
   → Visit: https://stackapps.com/apps/oauth/register
   → Fill in:
     • Application Name: PowerToys Run StackOverflow Plugin
     • Description: Personal use
     • OAuth Domain: localhost
     • Website: (optional)
   → Click "Register Your Application"
   → Copy the "Key" value (NOT Client Secret!)

2. CONFIGURE IN POWERTOYS SETTINGS
   → Right-click PowerToys tray icon → Settings
   → Go to: PowerToys Run → Plugins → StackOverflow
   → Find the textbox: "Stack Exchange API Key (Optional)"
   → Paste your key
   → Done! Key is saved automatically

3. VERIFY
   → Open PowerToys Run (Alt+Space)
   → Type: so python async
   → Search should work without rate limit errors
   → You now have 10,000 requests/day!
